Imports repeated HTML patterns from approved source pages into WordPress posts using saved scraping recipes.

== Description ==

WP Pattern Import lets an administrator define scraping patterns for source URLs, map fields to WordPress post data and meta, and run manual or scheduled imports.

The plugin creates new posts only. It does not update existing posts or delete missing posts.
